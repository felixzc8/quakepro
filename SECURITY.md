# Security policy

## Supported versions

Security fixes target latest released version. Before first release, they target
default branch.

## Report a vulnerability

Do not open public issue for a security vulnerability. Use GitHub's private
vulnerability reporting for this repository:

https://github.com/felixzc8/quakepro/security/advisories/new

Include steps to reproduce, affected version, impact, and any suggested fix.
Maintainers will acknowledge report and work with you on disclosure.
